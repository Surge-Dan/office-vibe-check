# 打工人体质检测器 · 小红书小组件工程

这是一个单页面原生小红书小组件工程：所有首页、答题和结果内容通过 `pages/index/index` 的 `home / quiz / result` 状态切换完成。

## 导入

请使用小红书官方开发者工具当前的小组件模板，将本目录作为项目根目录导入。不同版本 IDE 的项目配置字段和样式文件后缀可能不同，若官方模板自动生成配置文件，应以官方模板为准并保留本项目的页面、数据和逻辑文件。

官方代码构成要求的文件类型是 `.json`、`.xhsml`、`.CSS` 和 `.js`；根目录包含 `app.json`，页面位于 `pages/index/index`。本工程按该结构提供。[小红书小组件代码构成](https://miniapp.xiaohongshu.com/doc/DC602239)

## 平台边界

- 单页面；
- 不接网络、不接登录、不申请用户身份权限；
- 不使用支付、交易、导航和第三方 SDK；
- 不放置外部图片、远程字体或 CDN；
- 包体积必须小于 2MB；
- 结果档案直接在唯一页面内渲染，不假设小程序专属 Canvas 或相册保存 API；
- 分享使用页面 `onShareAppMessage` 和按钮 `open-type="share"`，用户可通过平台分享入口带走结果。

小组件目前处于官方邀请制灰度阶段，是否可创建和发布以账号后台实际资格为准。
