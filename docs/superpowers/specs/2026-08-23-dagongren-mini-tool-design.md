# 《班味鉴定所》离线 H5 小工具适配设计

版本：v1.0  
日期：2026-08-23  
状态：已获确认，进入实现

## 1. 目标与边界

将现有“打工人体质”题库和视觉方向适配为小红书官方离线 H5 小工具 ZIP。该版本面向发布后台截图所示的“上传 ZIP”入口，不替代仓库中已有的原生 XHSML 版本。

交付包必须满足：根目录存在 `index.html`；所有脚本、样式和数据均为包内相对路径；不联网、不登录、不申请权限、不使用外链、内联脚本、行内事件、`eval`、`iframe`、下载或剪贴板；ZIP 解压后不多套一层目录。

## 2. 信息架构

单页三态：

```text
首页 -> 7 道单选题 -> 结果档案
  ↑          ↓             ↓
  └── 上次结果        再测一次 / 选中文案手动复制
```

- 首页：工具名、职场档案局视觉、开始测试、最近结果入口。
- 答题：一次展示一道题，4 个选项，进度、返回和继续；返回不丢答案。
- 结果：体质代码、名称、短批注、标签、解释和再测；结果保存在 `localStorage`。
- 分享：不调用未确认的分享或剪贴板能力；结果文案可被选中，用户可长按复制。

## 3. H5 工程结构

```text
dagongren-mini-tool/
├─ index.html
├─ main.js
├─ quiz-core.js
├─ style.css
├─ tool-icon.png
├─ questions.js
└─ types.js
```

为兼容发布后台的实际上传校验，源码和最终 ZIP 均采用扁平根目录，不使用 `assets/` 或 `data/` 子目录；所有引用统一使用 `./文件名`。

数据使用经典脚本挂载到 `window`，不使用 ES Module，确保离线 WebView 直接加载。业务逻辑拆为题库、结果计算和页面状态三层，页面只通过 DOM 事件连接它们。

## 4. 视觉方向

主题是“职场档案局”，不是通用测评 Dashboard：

- 墨黑 `#171717`：像办公室夜班后的档案底纸；
- 暖白 `#F4F0E8`：阅读底色；
- 荧光黄绿 `#D7F36B`：选中和关键状态；
- 珊瑚红 `#E7795B`：行动按钮和警示印章；
- 灰褐 `#A9A49B`：编号、辅助说明。

页面记忆点是“档案标签 + 体质色条 + SPECIMEN 编号”，只保留一处视觉冒险，避免渐变、玻璃拟态、机器人和泛 AI 装饰。按钮使用明确的 pressed 状态、可见焦点和 `prefers-reduced-motion` 保护。

## 5. 错误与边界

- 未选择选项时不进入下一题，并给出就地提示。
- 跨题答案、缺失答案、非法题目和异常缓存不得生成结果。
- 非法或过期的结果变体回落到该体质第一条批注。
- `localStorage` 不可用时仍可完成当前测试；只放弃“最近结果”能力。
- 页面所有资源缺失、外链和禁用能力在打包前静态检查。

## 6. 验收标准

- 题库 7 题 × 4 选项，8 种体质全部可达，每种至少 5 条短批注。
- 首页、答题、返回、完成、结果、重测、最近结果流程可运行。
- 相同答案得到相同体质和同一条批注。
- `index.html` 根入口、脚本外置、资源相对引用、无禁用能力。
- ZIP 小于 10MB，建议远低于 2MB，且只包含官方允许的文件类型。
- Node 核心测试、静态契约测试、浏览器 Playwright 流程和解压包审计全部通过。
