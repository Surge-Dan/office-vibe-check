# 班味鉴定所：全行业语境与视觉表达升级设计

## 背景

当前测评模型已经具备动态路径、九维度评分、动物体质和高清报告，但题干存在互联网/产品经理语境偏置，结果动物是轻量线稿，过渡文案固定且使用“工位本能”，页面与导出图的中文字体层级也不够明确，发布笔记文案偏短。

本次升级不重做评分模型，不为每个行业复制一套题库，而是增加用户职场语境，使用通用情境题库和低强度语境词包覆盖更多行业与岗位。

## 目标与非目标

### 目标

1. 用户答题前可以选择行业与岗位，也可以跳过，首次参与成本不超过一个轻量步骤。
2. 题干不依赖互联网、产品、研发、上线等专属词，行业和岗位只对少数场景语气做确定性适配。
3. 报告动物与结果类型稳定对应，并从简单头像升级为有轮廓、纹理、阴影和印章错位感的手绘档案图。
4. 过渡页面根据答题阶段和高分维度从本地文案池确定性抽取，避免每次固定同一句。
5. 页面与导出图形成清晰字体层级：正文使用中性无衬线回退，大标题使用人文衬线回退，英文/数字使用等气质西文字体。
6. 发布笔记保留抽象、轻微厌世和搞怪语气，增加具体表现与反转句，同时遵守现有发布能力边界。

### 非目标

- 不引入网络字体、CDN、远程图片或新的运行时依赖。
- 不为每个行业建立独立评分模型或完整题库。
- 不把结果用于心理诊断、招聘、绩效或职业定论。
- 不改变九维度名称、动态路由的总体长度和小红书离线 H5 能力边界。

## 方案

### 1. 职业语境入口

首页新增两个单选组：

- 行业：互联网/科技、政企/公共服务、教育/科研、金融/商业、医疗/健康、制造/工程、零售/服务、传媒/内容、自由职业/其他。
- 岗位：管理/带人、专业/技术、运营/执行、销售/客户、支持/职能、创作/研究、个体经营/自由职业。

用户可以选择“先不标注，直接开始”。语境对象保存到 session 和 report，旧缓存没有 context 时按“跨行业通用”恢复，不破坏历史报告。

### 2. 通用题库与轻量适配

现有评分权重继续使用。新增 `context.js` 维护行业和岗位选项、通用词语映射及少量场景替换规则。题目渲染时根据 context 替换“项目/需求/合作方/汇报”等词为更宽泛或行业轻微适配的表达，默认文本本身也必须可以脱离互联网语境理解。

替换规则只允许一层、确定性、无 HTML 插值，避免用户输入进入 DOM。没有映射的行业统一使用通用文本。题目质量测试检查通用默认路径不包含“产品经理、研发上线、需求评审、互联网”等专属词。

### 3. 手绘档案动物

`animals.js` 继续作为唯一动物绘制入口，使用 `code` 作为种子。每种结果固定拥有轮廓族、耳/角/鬃毛结构、眼神、面部纹理和局部阴影参数；绘制顺序为纸张底色、外轮廓、第二条错位印章线、动物主体、特征线、纹理与少量颗粒线。

页面头像与导出报告复用相同的绘制函数，确保结果类型和视觉类型始终一致。仍使用 Canvas 2D，Canvas 不可用时保留文字报告。

### 4. 动态过渡文案

新增本地 `transition-copy.js` 或等价数据层，文案按阶段、重点维度和 context 选择。文案风格使用“职场反应、打工反射、求生动作、默认处理方式”等词，禁止“工位本能”。选择函数必须是纯函数，同一个 route、answers 和 context 得到同一结果，便于缓存和测试。

### 5. 字体和排版

根据 `chinese-font-selector`：

- UI 正文：思源黑体 / MiSans / 系统无衬线回退。
- UI 与导出大标题：思源宋体 / 人文衬线回退，限制在标题与结果名。
- 标签、英文和数字：Inter / Source Sans / monospace 回退，并将西文字体放在中文字体前。
- 正文行距 1.5–1.8，标题行距 1.2–1.3，中文标题只做轻微字距调整。

不内置全量字体文件，避免包体和首屏风险；CSS 和 Canvas 字体栈使用可审计的本地/系统回退，不声称目标设备一定安装某一字体。

### 6. 发布文案

`shareContent` 由结果类型、verdict、语境和两条高分维度生成：第一句给出怪诞标签，第二段描述真实职场表现，第三句用自嘲反转收尾，最后附 `#打工人体质 #班味鉴定所` 与一个结果相关话题。标题继续限制 20 字，正文保留 1000 字以内，并测试换行、特殊字符和缺少 report 字段时的兜底。

## 数据流与兼容

```text
首页选择 context
  -> session {context, index, route, answers}
  -> 渲染题干时做安全的本地语境映射
  -> createReport(answers, route, context)
  -> report {context, primary, secondary, dimensions, shareContent}
  -> 页面报告 / Canvas 导出 / postNote 共用同一 report
```

旧版 session/report：缺少 context 时填充通用默认值；字段不合法时清理缓存并回到首页。行业和岗位只作为语境信息与文案输入，不参与维度分数，保证不同用户之间结果仍然可解释。

## 验收标准

- 首页可完成行业/岗位选择、跳过选择、刷新恢复；非法值不会进入题干或 report。
- 至少覆盖 9 个行业和 7 个岗位；默认题库与报告不出现互联网专属术语。
- 54 道题、动态路线 18–21 题、22 种结果与九维度评分原有测试继续通过。
- 同一结果 code 的头像像素输出稳定；不同 code 至少在轮廓或特征线层面产生差异；页面与导出图一致。
- 过渡文案在不同阶段/维度下有多条可用结果，禁止“工位本能”，且同一输入可复现。
- 字体 CSS 与 Canvas 均不加载远程资源，导出图在 1080×2400 下无文字溢出。
- 发布文案长度、话题、缺省值和 Bridge 失败均有测试。
- 最终 ZIP 根目录平铺，离线浏览器测试、响应式截图和官方能力边界检查通过。
