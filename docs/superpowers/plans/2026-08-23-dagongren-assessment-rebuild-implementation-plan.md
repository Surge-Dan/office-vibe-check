# 班味鉴定所动态测评重构实施计划

## 目标

一次性交付 54 题、九维动态路由、22 类动物人设、完整报告、雷达图、1080×2400 图片导出与小红书 Bridge 保存/发布能力，并保持离线 H5、经典外置脚本和全扁平 ZIP。

## 全局约束

- 以 `docs/superpowers/specs/2026-08-23-dagongren-assessment-rebuild-design.md` 为唯一产品规格。
- ZIP 根目录直接包含 `index.html`，不允许任何子路径。
- 不联网，不使用模块、内联脚本、行内事件、剪贴板、下载、Worker、WASM、外链或未列入官方文档的 Bridge API。
- 同一答案序列必须得到同一路径、分数、结果与报告。
- 只修改离线 H5、对应测试、README 和最终 ZIP；不改原生 XHSML 小组件。

## 任务 1：题库、维度、人设与动态引擎

1. 先改写 Node 契约测试，断言 9 维、54 题、22 人设、4 选项、合法权重和完整文案字段。
2. 添加动态路径测试：12 锚点后选三维各两题；按冲突追加 0–2 校准题；按组合追加 0–1 隐藏题；总长 18–21。
3. 添加实际路径归一化、置信度、确定性、返回改答和原型匹配测试。
4. 实现 `dimensions.js`、`questions.js`、`archetypes.js`、`assessment-engine.js`。
5. 运行核心测试至全绿，并执行确定性模拟与结果分布审计。

## 任务 2：单页答题、报告与视觉

1. 先更新静态 DOM 契约与浏览器流程测试，覆盖首页、动态进度、过渡页、返回改答、完整报告、最近报告和重测。
2. 重写 `index.html` 与 `main.js` 状态机；实现会话缓存和题库版本失效策略。
3. 实现 `animals.js`、`radar-renderer.js`、`report-renderer.js`。
4. 重写 `style.css`，按“职场动物观察所”执行：档案纸、检材编号、橡皮章动物、批注线；响应 360/390/430 宽度、键盘焦点与 reduced motion。
5. 运行浏览器自动化，检查移动端截图、控制台、页面错误与外部请求。

## 任务 3：高清导出、平台能力、打包与文档

1. 先添加导出尺寸、非透明背景、Bridge 成功/拒绝/缺失/失败契约测试。
2. 实现 `exporter.js`：Canvas 生成 1080×2400 JPEG；`writeTempFile` 后 `saveImageToPhotosAlbum`；`postNote` 传完整 data URI。
3. 更新 README：产品机制、权限选择、功能、目录、测试、打包、发布与验证边界。
4. 生成全扁平 `dagongren-mini-tool.zip`，解压到临时目录后再次运行静态与浏览器流程。
5. 执行官方能力扫描、包体积审计、代码审查，修复全部关键问题后提交并推送 `main`。

## 视觉执行摘要

- 色彩：档案白 `#F3F0E8`、复写蓝 `#2457D6`、检验红 `#E8513D`、油墨黑 `#181815`、荧光便签 `#D9F45B`。
- 字体：标题用系统宋体栈，正文用系统黑体栈，编号与数据用等宽字体栈。
- 布局：首页是一张正在被鉴定的档案封面；答题是一页一问的现场记录；结果是一张纵向动物档案长卷。
- 记忆点：每种结果都有可同时用于 DOM 与 Canvas 的原创橡皮章动物符号。
- 自检：去掉通用深黑控制台、渐变光晕、玻璃卡片和无意义数字装饰；所有编号只表示真实题号、样本号或维度值。
